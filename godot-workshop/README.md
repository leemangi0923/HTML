# 1과제 Godot 작업실 — 첫 실행판 0.1.0

Godot를 처음 켠 사용자가 가져와 바로 실행하는 프로젝트입니다. 기존 HTML은 별도로 유지합니다.

## 처음 열기

1. 다운로드한 ZIP을 **압축 풀기** 합니다. ZIP 안에서 바로 열지 마세요.
2. Godot 프로젝트 관리 창에서 **가져오기(Import)** 를 누릅니다.
3. 압축 푼 폴더의 **project.godot** 파일을 선택하고 **가져오기 및 편집**합니다.
4. 이미지 가져오기가 끝나면 **F5**를 누릅니다. 주 장면은 이미 지정되어 있습니다.
5. 비밀번호 **0923**을 입력하고 **작업실 들어가기**를 누릅니다.

Godot 일반/GDScript 버전을 사용합니다. .NET/C#이나 추가 플러그인은 필요하지 않습니다. Compatibility 렌더러를 기본으로 지정했습니다. 자동 테스트는 Godot 4.6.3 Linux에서 수행했습니다. Godot 4.6 이상을 대상으로 만들었으며 사용자의 4.7.2에서도 가져올 수 있는 기본 4.x 기능만 사용합니다. Windows 실기기에서의 실행 검증은 아직 하지 않았습니다.

## 조작

- WASD / 방향키: 걷기
- 마우스: 둘러보기
- Shift: 빠르게 걷기
- C 누르고 있기: 앉기
- E: 바라보는 기구의 이름 확인
- R: 작업대 앞으로 돌아오기
- Esc: 마우스 해제·메뉴·계속하기
- F8: Godot 에디터에서 실행 중지

## 이번 버전 범위

방, 1인칭 이동, 바닥·벽·작업대 충돌, 앉기, 정지 메뉴와 복귀를 먼저 확인합니다. 제어판 760×600mm, 조작판 375×270mm, 컨베이어 500mm와 기구 19개의 평면 위치는 HTML의 완성 예제에서 가져왔습니다. 원본 기구 그림을 PNG로 변환해 글자가 사라지지 않도록 했습니다. 기구 높이와 방·책상 치수는 교육용 근사치입니다.

**최종 교복 캐릭터, 손 도구 조작, 배선 편집·전기 동작·전체 채점은 아직 포함하지 않았습니다.** 이전의 단순 도형 캐릭터를 최종 교복 모델처럼 재사용하지 않았습니다. 이번 프로젝트에서 이동·작업대 크기를 확인한 뒤 모델과 상호작용을 순서대로 추가합니다.

비밀번호는 로컬 데모의 입장 화면일 뿐, 배포 파일 자체를 보호하는 서버 인증이 아닙니다. 실제 로봇이나 제어기에 연결하지 않습니다.

## 개발·검증

`scenes/workshop.tscn`이 주 장면이고 `scripts/workshop.gd`가 방·입장 화면·메뉴, `player.gd`가 이동, `workbench.gd`가 작업대 표시를 담당합니다. 작업실은 실행할 때 생성되므로 에디터에서 빈 장면이 보이더라도 F5로 실행하면 됩니다.

```sh
godot --headless --editor --path . --quit
godot --headless --path . --fixed-fps 60 --script tests/smoke.gd
```

검증: 초기 잠금, 오입력, 0923 입장, 이동, 바닥 착지, 작업대 충돌, 앉기, 메뉴 중 정지, 위치 복귀, 기구 19개 로드. Linux 가상 X 디스플레이에서 Compatibility 렌더러로 실제 장면과 입장 화면도 렌더링해 확인했습니다.

작업대 자료 갱신: 저장소 루트에서 `CHROMIUM_PATH=/usr/bin/chromium node scripts/prepare-godot-assets.cjs`를 실행합니다. ZIP 갱신: `python3 scripts/package-godot.py`.
