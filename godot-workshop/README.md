# 1과제 Godot 작업실 — 교복 캐릭터 0.5.0

Godot를 처음 켠 사용자가 가져와 바로 실행하는 프로젝트입니다. 기존 HTML은 별도로 유지합니다.

배포 파일은 `task1-godot-v0.5.0.zip`이며, 실행 화면 상단에서도 버전을 확인할 수 있습니다.

0.5.0 1차: 준비된 일반선 120개와 긴 선 9개만 지급합니다. 자르기·탈피·압착 과정은 없습니다. 실제 길이가 아직 정해지지 않아 `scripts/wiring.gd`의 `LENGTH`에 일반 1.2m, 긴 선 4m를 임시로 설정했습니다. 오른쪽 재료대에서 집어 작업대 앞의 추가 연습 단자대 X1~X6에 양끝을 삽입합니다. 재고·한쪽 삽입 상태·양쪽 나사 상태가 자동 저장됩니다. 손이 닿지 않으면 가까이 가거나 C로 낮춰야 합니다. 빈손일 때 자동으로 두 팔을 들던 자세 전환을 제거하고 조작 시 오른팔만 목표에 접근하도록 했습니다.

조작: 재료대나 단자에 조준하고 E 집기/삽입, F 조임/풀기, Q 들고 있는 선 반납, X 양쪽 나사가 풀린 연결선 분리·반납, Z 마지막 배선 동작 되돌리기. 일반 120개·긴 선 9개는 들고 있는 선까지 포함해 계산합니다. 조인 쪽을 풀기 전에 반납할 수 없습니다. 한쪽이 연결된 선을 잡고 멀리 이동하면 전선 길이에서 이동이 제한됩니다. 주황색 작은 표시는 삽입·미조임, 녹색은 조임 상태입니다.

이번 단계는 **추가 연습 단자대의 연결 조작 시제품**입니다. 기존 기구 전체 단자나 회로 동작과 아직 연결되지 않았습니다. F는 나사 상태 전환이며 실제 드라이버 집기·회전은 다음 단계입니다. 전선은 길이를 유지하는 곡선이며 모든 물체와 충돌하는 물리 전선은 아닙니다. 캐릭터도 승인된 2D 시안과 같은 품질로 재현된 완성 모델이 아닙니다.

0.3.0: 1인칭 카메라의 숨김 설정 때문에 빠졌던 머리 그림자를 복구했습니다. 화면에는 머리를 보이지 않고, 같은 스킨·관절을 공유하는 그림자 전용 메시로 머리·목·머리카락을 바닥에 투영합니다. 고개를 숙이면 머리 그림자도 따라 움직입니다. 옷감의 직물 노멀·거칠기, 허리·팔꿈치·무릎 주름, 옆선·소매 봉제선과 연속된 회색 어깨 배색을 추가했습니다. 걷는 속도에 따른 작은 시점 움직임, 좌우 이동 기울기, 뒤로 걷는 발 동작을 적용하고 과하게 밝던 조명을 줄였습니다.

## 처음 열기

1. 다운로드한 ZIP을 **압축 풀기** 합니다. ZIP 안에서 바로 열지 마세요.
2. Godot 프로젝트 관리 창에서 **가져오기(Import)** 를 누릅니다.
3. 압축 푼 폴더의 **project.godot** 파일을 선택하고 **가져오기 및 편집**합니다.
4. 이미지 가져오기가 끝나면 **F5**를 누릅니다. 주 장면은 이미 지정되어 있습니다.
5. 비밀번호 **0923**을 입력하고 **작업실 들어가기**를 누릅니다.

Godot 일반/GDScript 버전을 사용합니다. .NET/C#이나 추가 플러그인은 필요하지 않습니다. Compatibility 렌더러를 기본으로 지정했습니다. 자동 테스트는 Godot 4.6.3 Linux에서 수행했습니다. Godot 4.6 이상을 대상으로 만들었으며 사용자의 4.7.2에서도 가져올 수 있는 기본 4.x 기능만 사용합니다. Windows 실기기에서의 실행 검증은 아직 하지 않았습니다.

## 조작

- WASD / 방향키: 걷기
- 마우스: 둘러보기
- Shift: 빠르게 걷기
- C 누르고 있기: 앉기
- E: 바라보는 기구의 이름 확인
- R: 작업대 앞으로 돌아오기
- Esc: 마우스 해제·메뉴·계속하기
- F8: Godot 에디터에서 실행 중지

## 교복 캐릭터

Blender에서 제작한 곡면 스킨 메시와 40개 변형 관절을 가진 캐릭터를 추가했습니다. 남색 앞몸판·안소매·바지, 회색 바깥 소매·등 위쪽, 가슴과 등의 밝은 띠, 지퍼를 가리는 남색 덮개와 윗부분 똑딱단추, 맨손·흰 밑창 신발을 표현합니다. 착용자 왼팔은 학교 마크, 오른팔은 WorldSkills KOREA입니다. 학교 표기는 **국립전북기계공업고등학교 / 마이스터고 / Chonbuk Mechanical Technical High School**입니다.

1인칭에서 아래를 보면 몸·팔·다리·발이 보입니다. 머리와 어깨 마크는 1인칭 카메라에서 숨기고, 걷기·서기·쪼그려 앉기 동작을 전환합니다. 작업 준비 두 클립은 모델에 남아 있지만 빈손 상태에서 자동 재생하지 않습니다. 빈손일 때는 작업대 앞에서도 기본 자세를 유지하며, 실제 조작 시 오른팔에 목표 위치를 적용합니다. 머리를 숙여도 눈 위치가 머리 주위를 돌지 않도록 했습니다. 교복 전체보기 메뉴는 없습니다.

프로젝트의 GLB 모델과 애니메이션만으로 실행되므로 **Blender 설치나 플러그인이 필요 없습니다**. 원본 `.blend`와 재생성 스크립트는 저장소의 `art-source`와 `scripts`에 별도로 보관했습니다. 이미지 시안을 참고한 첫 캐릭터 모델이며 사진의 정밀 복제는 아닙니다.

## 이번 버전 범위

방, 1인칭 이동, 바닥·벽·작업대 충돌, 앉기, 정지 메뉴와 복귀를 먼저 확인합니다. 제어판 760×600mm, 조작판 375×270mm, 컨베이어 500mm와 기구 19개의 평면 위치는 HTML의 완성 예제에서 가져왔습니다. 원본 기구 그림을 PNG로 변환해 글자가 사라지지 않도록 했습니다. 기구 높이와 방·책상 치수는 교육용 근사치입니다.

**손가락별 잡기, 손 도구 조작, 배선 편집·전기 동작·전체 채점은 아직 포함하지 않았습니다.** 손가락은 각 두 관절의 준비 자세를 사용하며 실제 물체를 쥐지는 않습니다. 기구 상호작용은 다음 단계로 추가합니다.

비밀번호는 로컬 데모의 입장 화면일 뿐, 배포 파일 자체를 보호하는 서버 인증이 아닙니다. 실제 로봇이나 제어기에 연결하지 않습니다.

## 개발·검증

`scenes/workshop.tscn`이 주 장면이고 `scripts/workshop.gd`가 방·입장 화면·메뉴, `player.gd`가 이동, `workbench.gd`가 작업대 표시를 담당합니다. 작업실은 실행할 때 생성되므로 에디터에서 빈 장면이 보이더라도 F5로 실행하면 됩니다.

```sh
godot --headless --editor --path . --quit
godot --headless --path . --fixed-fps 60 --script tests/smoke.gd
godot --headless --path . --script tests/wiring.gd
# 실제 창/그래픽 드라이버를 사용할 수 있는 환경에서 그림자 회귀 검사
godot --path . --script tests/shadow_render.gd
```

검증: 초기 잠금, 오입력, 0923 입장, 이동, 바닥 착지, 작업대 충돌, 앉기, 메뉴 중 정지, 위치 복귀, 기구 19개 로드, 40관절 스킨 캐릭터, 옷감 재질, 걷기 애니메이션 선택, 앉을 때 몸 높이·무릎 방향·발 높이, 1인칭 머리/마크 숨김, 그림자 전용 메시, 뒤로 걷기, 정지 후 시점 안정, 실제 관절 위치로 측정한 팔꿈치 각도·굽힘 방향, 작업 자세 전환·해제, 앉은 작업 손목 높이. 그림자 검사는 실제 Compatibility 렌더러에서 1인칭 카메라로 바닥을 그려 머리 그림자의 유무에 따른 밝기 차이를 확인합니다. Linux 가상 X 디스플레이에서 서기·작업 준비·앉은 작업의 실제 장면도 렌더링해 확인했습니다.

작업대 자료 갱신: 저장소 루트에서 `CHROMIUM_PATH=/usr/bin/chromium node scripts/prepare-godot-assets.cjs`를 실행합니다. 배포할 때마다 `project.godot`의 `config/version`을 올린 뒤 `python3 scripts/package-godot.py`를 실행합니다. ZIP 파일명은 프로젝트 버전에서 자동으로 생성됩니다.
