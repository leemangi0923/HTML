프로젝트 v0.7.0 / task1-godot-v0.7.0.zip
1. 새 폴더에 압축을 풀고 Godot에서 project.godot을 가져오세요.
2. F5 실행 → 비밀번호 0923.
3. Tab을 누르면 제어판이 크게 보입니다.
4. 휠로 확대·축소 / 가운데 버튼을 누르고 끌어 화면 이동.
5. 1 제어판 / 2 조작판 / 3 컨베이어 / 4 전선 재료대.
6. 재료대에서 전선 클릭 → 1로 제어판 이동 → 단자 두 곳 클릭 → 각 단자에서 F로 조임.
7. M을 누르고 단자 두 개를 클릭하면 조인 전선의 경로를 추적합니다.
Q 전선 반납 / X 풀린 연결선 분리 / Z 되돌리기 / Tab 1인칭 복귀.
WASD 이동 / C 낮추기 / Esc 메뉴 / F8 실행 중지.
일반선 120개 + 긴 선 9개. 기존 작업과 재고는 자동 저장·복원됩니다.
길이 임시값: 일반 1.2m, 긴 선 4m. 전체 회로의 전원·전기 동작 계산은 아직 미포함.
