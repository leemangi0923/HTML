# 로봇 연동장치 조립 시뮬레이터

`index.html`을 브라우저에서 실행하는 단일 파일 앱입니다. 앱 실행에는 Node.js나 패키지 설치가 필요하지 않습니다.

```sh
python3 -m http.server 8000 --directory .
```

## 2.7.1 헬리컬 밴드 안의 전선 고정

밴드를 감은 뒤 케이블 타이를 묶거나 옮겨도 밴드 안의 전선과 덕트 쪽 경로는 고정됩니다. 밴드가 끝나는 곳부터 조작판 단자까지 드러난 전선만 부드럽게 움직입니다. 일부만 감았을 때는 실제로 감싼 구간만 고정하고 양쪽 노출 부분을 각각 움직입니다. 기존 배선·타이·저장 형식은 유지합니다.

## 2.7.0 검토한 100문제 문제은행

1과제 퀴즈를 공구(20)·기구/재료(20)·설치/가공(15)·전선/배선(20)·동작/진단(15)·안전/마무리(10), 총 100문제로 확장했습니다. 사용자 검토 번호를 그대로 유지하며, [전체 출제 목록](docs/quiz-bank.md)에서 질문·정답·오답·해설과 개념도 조건을 확인할 수 있습니다.

모든 문제는 4지선다이며 문제·선택지를 섞고 한 바퀴 안의 중복과 바퀴 경계의 연속 중복을 방지합니다. 일일 제한·복습 기능은 없습니다. 실습 상태·저장·채점에는 영향을 주지 않습니다.

그림은 단일 HTML에 포함된 SVG로, 실제 사진이 아님을 표시합니다. 공구·기구 식별, 불량 상태, 타이 절단 비교, 접속점과 타이머 개념도를 제공합니다. 76~78번은 PLC 전원과 운전 허가 입력을 구분하는 **출제용 개념도**로 전제 조건과 귀환선·공통선 생략을 명시하며 실제 시험 도면으로 취급하지 않습니다. 87번은 전원 투입형·비유지형과 충분한 초기화 시간을 명시합니다. 안전 해설에는 전원 차단·재투입 방지·지정 방전·무전압 확인 및 확인 전후 계측기 검증을 반영했습니다. 검토에 사용된 제조사 자료는 관련 문항의 해설에서 연결합니다. 앱의 ‘페놀’ 표기는 ‘페룰’로 통일했습니다.

## 2.6.1 1과제 지식 퀴즈

일반 회로 상식 문제를 공구(8)·재료(6)·작업 요령(6) 총 20문제로 교체했습니다. 몽키 스패너·니퍼·스트리퍼·페룰 단자 압착기·십자드라이버·줄자와 덕트·찬넬·페룰·타이·헬리컬 밴드를 직접 그린 인라인 SVG 그림으로 식별합니다. 실제 사진은 아니며 화면에도 그림임을 표시합니다. 외부 이미지 요청 없이 단일 HTML에서 실행됩니다.

모두 4지선다이며 해설에서 사용법과 관련 작업을 설명합니다. 문제에 붙은 ‘이 앱’ 작업 순서는 시뮬레이터 기준이며, 공통 안전 요령과 구분합니다. 무작위·중복 방지·세션 집계는 유지하고, 복습 기능과 일일 제한은 없습니다.

## 2.6.0 회로 퀴즈

메인 화면 오른쪽 아래의 **회로 퀴즈**에서 20문제를 풀 수 있습니다. 전체 또는 기구(6)·접점(6)·타이머(4)·회로(4)를 선택하면 문제와 선택지가 무작위로 섞입니다. 같은 범위의 문제를 모두 풀기 전에는 중복 출제하지 않으며, 다음 바퀴의 첫 문제도 직전 문제와 다릅니다.

답을 고르면 정답과 짧은 해설을 표시하며, 접점 문제는 현재 코일 상태에 따른 열림·닫힘 그림도 보여줍니다. 시간·일일 횟수 제한과 복습 기능은 없습니다. 풀이 수는 현재 세션에서만 집계하고, 범위를 바꾸거나 메뉴에서 새로 시작하면 초기화합니다. 실습 배선·저장·채점 기록에는 영향을 주지 않습니다.

## 2.5.3 표시등 진입 경로 정리

왼쪽으로 진입하는 표시등 배선에 남아 있던 위쪽 고리를 없애고, 연결 방향으로 바로 이어지는 곡선으로 바꿨습니다. 기존 저장 작업의 타이는 새 전선 경로에 맞춰 한 번 옮기며 연결 대상·개수·조임 상태를 유지합니다.

## 2.5.2 마우스 조작 성능

바뀌지 않은 전선의 경로·거리 계산 자료를 재사용하고, 포인터 강조를 화면 프레임에 맞춰 한 번만 그립니다. SVG 내용이 같으면 DOM을 교체하지 않습니다. 전선 수정·되돌리기·타이 이동 시에는 계산 자료를 다시 만듭니다.

JavaScript와 CSS를 별도 파일로 옮기는 것 자체는 프레임 개선이 아니므로 단일 HTML 실행 방식은 유지합니다. 측정 방법과 결과는 [성능 점검](docs/performance.md)에 있습니다.

## 2.5.1 표시등 배선 모양

HMI 아래쪽 표시등의 전선은 단자 왼쪽에서 들어오도록 90도로 꺾입니다. 같은 나사에 연결한 두 선은 위아래로 나란히 놓이며, 케이블 타이로 묶어도 단자 옆 직선 구간을 유지합니다. 전기적 연결과 저장 형식은 바뀌지 않습니다.

## 2.5 단자대와 배선 자유도

- 상단 **단자대 견출지** 또는 **견출지(L)** 도구로 단자대의 흰 이름표를 눌러 편집합니다. 빈칸·중복 이름도 가능하며 이름표는 전기적 기능을 지정하지 않습니다.
- S+ 등 외부 선을 다른 번호로 옮겨도, 내부 배선과 외부 결선이 함께 맞으면 실제 회로로 작동·검사합니다. 단자대 번호만으로 AC/DC를 정하지 않습니다.
- 전원 케이블은 꽂을 R선 단자와 T선 단자를 차례로 선택합니다. 전원 위치도 이름표와 별개이며 1·2번으로 고정되지 않습니다.
- 배선 목록에서 예시와 다른 선을 오답으로 표시하지 않습니다. 배선 검사는 외부 전원선과 컨베이어 선을 연결한 뒤 진행합니다.
- 추가로 발견한 고정 조건과 남은 한계는 [배선 자유도 점검](docs/wiring-flexibility.md)에 정리했습니다. 연습용 예시·배치·조작판 조건이 모두 자유화된 것은 아닙니다.

## 2.4 초보자를 위한 기구 해설

**기구 해설(I)** 도구로 설치된 기구를 누릅니다. 기본 화면은 다음 순서로 보여줍니다.

1. 기구의 실제 모양과 하는 일 한 줄
2. 현재 내 배선에서 계산한 상태
3. 릴레이는 두 갈래 길 그림, 타이머는 3단계 순서와 남은 시간
4. 직접 조작해 볼 방법이나 꼭 기억할 내용

단자 번호·모델명·전문 결선도는 **단자 번호·자세한 정보가 필요할 때**를 펼쳐서 확인합니다. 다른 기구로 바꾸면 다시 접힙니다. 창을 열어 둔 채 손(H) 도구로 버튼과 센서를 조작하면 그림과 설명도 실시간으로 바뀝니다. 해설을 보는 것만으로 기구나 배선이 바뀌지는 않습니다.

시험 중에는 해설을 숨기며 제출 뒤 다시 사용할 수 있습니다. 작업판에 선이나 접점 상태를 덧그리는 기능은 없습니다. 기존 저장 데이터 형식도 유지합니다.

## 2.2 기능

- 채점표의 미완료·감점 항목에서 **관련 위치 보기**를 누르면 부품이나 단자로 이동하고 빨간색으로 강조합니다. 자유 모드와 시험 제출 후에 사용할 수 있습니다. 동작 항목은 검사할 관련 부품·단자를 보여주며, 구체적인 원인은 감점 설명과 테스터로 확인합니다.
- **단자 검색**에서 `R3`, `PLC P20`, `TB 1번`, `부저`처럼 기호나 한글 이름으로 설치된 단자를 찾습니다. 조작판 단자는 필요하면 뒷면으로 전환합니다.
- **연결 추적**은 현재 꽂은 전선, 단자대 위아래·SMPS 공통선, 컨베이어 결선을 따라 연결된 단자와 전선을 강조합니다. 접점의 통전 상태와 전압은 테스터로 확인합니다.
- 강조는 Esc, **강조 지우기**, 작업 변경·초기화·모드 전환 시 해제됩니다. 저장 데이터 형식은 기존 버전과 같습니다.

## 자동 검증

Node.js 20 이상이 필요합니다.

```sh
npm ci
npx playwright install chromium
npm test
```

Linux에서 브라우저 시스템 라이브러리도 필요하면 `npx playwright install --with-deps chromium`을 사용합니다. 기존 Chromium을 사용할 때는 `CHROMIUM_PATH=/usr/bin/chromium npm test`로 실행합니다. npm 캐시 경로가 쓰기 금지된 환경에서는 `npm ci --cache /tmp/html-npm-cache`를 사용할 수 있습니다.

검증은 임시 로컬 HTTP 서버와 별도의 브라우저 저장 공간을 사용하며 사용자 작업은 건드리지 않습니다. 외부 폰트 없이도 실행합니다.

검증 대상:

- 정답 배선의 회로 검사 15개, 컨베이어 동작 검사 11개, 만점 30점
- 고장 10종 각각의 검출·감점 및 복구 후 통과
- 채점 위치 이동과 작업 상태 보존
- 기호·한글 검색, 실제 배선 추적, 검색 입력 중 도구 단축키 방지
- 빈 작업, 모드 전환, 시험 중 채점 위치 안내 제한
- 자유·시험 작업의 독립 저장 및 새로고침 복원
- 모바일 화면의 검색창과 위치 이동
- 릴레이의 실제 4극 전환과 초보자용 길 그림, 타이머 순시·한시·남은 시간과 전원 OFF 복귀
- 표시 접점과 회로 계산의 일치, 미장착 소켓, 기구 해설의 읽기 전용 조작
- 모든 설치 기구의 쉬운 역할·현재 상태, 기본 화면에서 전문 용어와 단자 정보 숨김
- 선택형 상세 정보, 작업판 접점 표시 제거, 시험 제한, 좁은 화면·어두운 테마의 해설 창

GitHub Actions는 push와 pull request에서 같은 검증을 실행합니다. 브라우저 조립 작업 전체를 수동으로 완주하는 테스트는 포함하지 않습니다.
