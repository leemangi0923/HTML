## 2.12.1 교복 전체보기 제거

사용자 요청으로 교복 전체보기 버튼과 별도 전시 화면을 제거했습니다. 1인칭 몸 모델, 작업대 둘러보기, 비밀번호 입장은 유지합니다.

## 2.12.0 교복 몸 모델과 작업실 비밀번호

3D 작업실과 작은 회로 체험 모두 입장 비밀번호 **0923**을 확인합니다. 메인 메뉴와 직접 주소 접근에 같은 입장 화면을 적용하고, 확인 전에는 3D 모듈·기구 자료를 불러오지 않습니다. 같은 탭에서는 확인 상태를 `sessionStorage`로 유지하며 상단 **잠그기**로 해제합니다. 저장소 사용이 차단된 브라우저에서도 현재 입장은 가능하지만 새로고침 때 다시 확인합니다. 원본 1과제 화면에는 비밀번호를 요구하지 않습니다.

이 기능은 **정적 HTML의 클라이언트 입장 잠금**입니다. 비밀번호와 자료를 서버에서 보호하는 인증 기능이 아니며, 소스 코드·개발자 도구로 우회할 수 있습니다. 서버 수준의 접근 통제가 필요하면 별도의 호스팅 인증이 필요합니다.

사용자가 확정한 남색·회색 교복을 입체 몸 모델에 반영했습니다. 가슴/등의 밝은 띠, 지퍼를 가리는 남색 덮개와 맨 위 똑딱단추, 회색 소매·남색 시보리, 장갑, 남색 바지, 밝은 밑창을 표현합니다. 착용자 왼팔은 학교 마크, 오른팔은 WorldSkills KOREA이며 학교 표기는 **국립전북기계공업고등학교 / 마이스터고 / Chonbuk Mechanical Technical High School**입니다. 마크는 제공된 사진을 참고해 SVG로 단순화했으며 실제 자수의 정밀 복제는 아닙니다. 원본 학생 사진을 앱에 포함하지 않습니다.

교복 전체보기는 2.12.1에서 제거했습니다. **1인칭으로 걷기**에서 아래를 보면 몸통·팔·다리·신발이 보이며, 머리와 어깨 마크는 1인칭 카메라에서 표시하지 않습니다. 머리를 충분히 숙일 수 있도록 아래 보기 각도를 늘렸고 걷기·앉기에 다리 관절 동작을 반영했습니다. 실제 렌더링은 브라우저용 단순화한 모델로, 이미지 시안과 렌더 품질은 다릅니다.

## 2.11.0 1인칭 작업실과 입체 기구

**3D 작업대**가 사람 눈높이의 1인칭 화면으로 시작합니다. **작업실 들어가기**를 누르면 마우스로 둘러보고 WASD/방향키로 걷습니다. Shift로 빠르게 이동, C를 누르는 동안 앉기, E/마우스 클릭으로 화면 가운데 기구 이름 확인, Esc로 마우스 해제를 지원합니다. 키는 화면에 들어가 포커스가 있을 때만 처리하고, Esc·창 포커스 이탈·숨김·마우스 잠금 해제 시 이동을 즉시 중단합니다. 마우스 잠금 미지원/거부 환경에서는 드래그로 둘러보기로 전환합니다.

몸·발·걸음 동작, 작업대/방 경계 충돌, 터치 이동 버튼, 앉기 버튼, 작업대 앞으로 복귀, 걸음 흔들림 끄기를 제공합니다. 모션 감소 설정에서는 걸음 흔들림을 기본으로 끕니다. 부분 보기와 위에서 보기 버튼은 돌려보기 모드로 전환하며, 1인칭 버튼으로 걷기에 돌아갈 수 있습니다. 작업실 크기·사람 눈높이·몸 반경·책상 높이는 가정입니다.

기존 평면 배치는 유지하면서 소켓·릴레이 투명 케이스/코일·타이머 다이얼/클립·PLC/SMPS 통풍구·서보 커넥터·단자 나사 345개·덕트 핑거 720개를 추가했습니다. 반복 부품은 InstancedMesh로 묶고 정적 그림자는 재사용합니다. 외부 사이트 없이 로컬 기구 그림으로 표시합니다.

제조사 사이트는 이 환경의 접속 제한으로 제품 사진·CAD·깊이 자료를 새로 확인하지 못했습니다. 입체 기구의 높이·깊이는 계속 근사치이며, 인터넷 실측 자료에 맞췄다고 주장하지 않습니다. 실제 조사 URL·결과와 모델링 한계는 [외형 조사 기록](docs/3d-reference-research.md)에 있습니다. 전체 1과제 조립·배선 편집·채점은 원본 화면을 사용합니다.

## 2.10.1 원본 작업대의 3D 배치

**3D 작업대**를 열면 원본 완성 예제와 같은 제어판 760×600mm·조작판 375×270mm·컨베이어 500mm 배치를 표시합니다. MCB·퓨즈 2개·SMPS·PLC·POS·서보·릴레이 6개·타이머 3개·XTB 2개·40칸 단자대와 덕트 6개·찬넬 3개를 원본 좌표로 옮겼습니다. 기구 윗면은 원본 SVG 그림을 재사용하고 각 기구를 입체로 올립니다. 가로·세로 치수와 위치는 원본 기준이며, 원본에 없는 높이는 근사치입니다.

조작판 앞/뒷면 전환, 부분별 확대, 기구 이름 확인, 완성 예제의 배선 경로 표시를 지원합니다. 배선 표시는 참고용이며 편집·회로 동작은 원본 화면에서 진행합니다. 앞면에서는 조작판 내부 배선을 숨깁니다. 기존 작은 회로 체험은 [24V 회로 체험](lab-3d.html?mode=circuit)에 유지했습니다. 저장 데이터를 새 작업대로 옮기거나 수정하지 않습니다.

`lab-3d/reference`의 치수·좌표·기구 그림·배선 경로는 `CHROMIUM_PATH=/usr/bin/chromium node scripts/export-workbench.cjs`로 원본의 격리된 예제 상태에서 다시 생성할 수 있습니다. 이 명령은 사용자의 저장 공간에 접근하지 않습니다.

## 2.10.0 3D 작업대 미리보기

메인 메뉴의 **3D 작업대**에서 별도의 [작은 회로 시제품](lab-3d.html?mode=circuit)을 엽니다. 단순한 입체 작업대에 24V 전원·누름 버튼·릴레이·표시등·6칸 단자대를 배치했습니다. 드래그로 회전, 휠로 확대, 휠 버튼/오른쪽 드래그로 화면 이동하며 단자 두 개를 눌러 배선합니다. 전원을 켜고 PB를 누르는 동안 예제의 릴레이와 불이 동작합니다. 전원 ON 중에는 배선을 변경하지 못하고, 전원 단락은 가상 전원을 차단합니다.

예제 불러오기·선 삭제·비우기·되돌리기·독립 자동 저장을 지원합니다. 단자대 같은 칸 위아래는 연결되며 예시와 다른 경로도 실제 연결망으로 계산합니다. 기존 자유·시험·연습 작업과 저장 키·채점 엔진은 공유하지 않습니다. 3D 리소스는 이 화면을 열 때만 로드합니다.

3D 화면은 **HTTP(S) 웹 주소**에서 실행하세요. 위의 로컬 서버 명령 또는 GitHub Pages를 사용하면 됩니다. file://로 열면 서버 실행 방법을 안내합니다. WebGL을 지원하는 브라우저가 필요하며, Three.js 0.160.1과 OrbitControls는 `vendor/three`에 포함해 CDN 요청 없이 실행합니다([MIT 라이선스](vendor/three/LICENSE)).

범위는 3D 조작과 간단한 정상개방 버튼·릴레이 a접점 회로 체험입니다. 실제 1과제 기구 모델, 전체 조립·채점, 타이머, 자기유지·발진 등 시간에 따른 접점 회로, AC 전원·전류·발열·정밀 충돌·덕트·타이·밴드 작업은 아직 옮기지 않았습니다. 원본 2D 시뮬레이터에서 계속 사용할 수 있습니다. 전선은 자동 곡선이며 사용자가 꺾임 위치를 지정하는 기능은 없습니다.

## 2.9.1 퀴즈 제거

메인 메뉴에서 퀴즈를 제거하고 문제은행·이미지·출제 화면·진행 저장 코드를 정리했습니다. 퀴즈를 대체하던 자리는 2.10.0에서 별도 3D 미리보기로 채웠습니다. 배선 오류 안내와 기존 연습·자유·시험·선 따기 연습·도움말은 유지합니다.

## 2.9.0 배선 오류 안내

일반 배선·전원 RTE·컨베이어 결선에서 거부된 연결의 양쪽 단자를 붉게 표시하고, 선택한 단자 이름·이유·다음 조치를 안내창에 표시합니다. ‘위치 보기’로 해당 지점을 확인하고, 성공적으로 연결하거나 닫기/Esc/모드 전환으로 안내를 해제합니다. 실제 회로 검사와 기존 연결 허용 기준·감점 여부를 유지합니다.

## 2.8.0 전원 케이블 갈·파·초 세 가닥 연결

전원 케이블은 **갈색 R·파란색 T·초록색 E** 순서입니다. 재료함에서 들어 제어판 아래 빈 바닥에 내려놓고, 각 선 끝과 단자대 아래쪽 단자를 차례로 눌러 한 가닥씩 연결합니다. 세 가닥이 모두 올바르게 연결돼야 정상 전원으로 인정합니다.

R/T는 실제 배선의 차단기 각 극에 맞아야 하며, E는 전원·직류 신호와 분리된 접지 전용 단자에 연결합니다. R/T 뒤바뀜, E의 전원·신호 오결선, 중복 단자, 닫힌 커버, MCB가 켜진 상태의 전원선 조작을 막습니다. 단자대 위치는 고정하지 않으며 내부 배선까지 맞게 옮긴 위치도 허용합니다. 연결 후 내부 배선을 바꾸거나 잘못된 저장 데이터를 읽어도 전원 회로를 재검사합니다. E 검사는 이 모델의 접지 전용 망 분리 확인 범위이며 접지 저항 등 실제 설비의 검사를 대신하지 않습니다.

연결한 선 끝을 다시 선택하면 그 한 가닥을 빼서 옮길 수 있습니다. 전원 케이블 몸체를 손으로 들면 세 가닥이 분리되며 다시 바닥에 놓을 수 있습니다. 부분 연결 상태·바닥 위치는 저장/되돌리기를 지원합니다. 기존 두 가닥 케이블 저장은 R/T 위치를 유지하고 접지 전용 단자를 찾아 E를 복원합니다. 연습·시연·할 일 안내도 세 가닥 방식으로 바뀌었습니다.

## 2.7.2 휠 버튼 화면 이동 최적화

휠 버튼 드래그·왼쪽 드래그·터치 확대의 카메라 반영을 프레임당 한 번으로 합칩니다. 드래그 시작 때 화면 크기를 읽어 재사용하고, SVG 갱신 직후 크기를 다시 읽는 작업을 줄였습니다. 이동 중에는 포인터 강조를 숨기고, 놓기·취소·포인터 캡처 해제·창 포커스 이탈 시 대기 중인 최종 위치를 동기화합니다. 확대 배율에 따른 기구 상세 표시도 유지합니다.

측정 방법과 한계는 [성능 점검](docs/performance.md)에 있으며 `CHROMIUM_PATH=/usr/bin/chromium npm run benchmark:pan`으로 입력 묶음 처리를 재현할 수 있습니다.

## 2.7.1 헬리컬 밴드 안의 전선 고정

밴드를 감은 뒤 케이블 타이를 묶거나 옮겨도 밴드 안의 전선과 덕트 쪽 경로는 고정됩니다. 밴드가 끝나는 곳부터 조작판 단자까지 드러난 전선만 부드럽게 움직입니다. 일부만 감았을 때는 실제로 감싼 구간만 고정하고 양쪽 노출 부분을 각각 움직입니다. 기존 배선·타이·저장 형식은 유지합니다.

## 2.5.3 표시등 진입 경로 정리

왼쪽으로 진입하는 표시등 배선에 남아 있던 위쪽 고리를 없애고, 연결 방향으로 바로 이어지는 곡선으로 바꿨습니다. 기존 저장 작업의 타이는 새 전선 경로에 맞춰 한 번 옮기며 연결 대상·개수·조임 상태를 유지합니다.

## 2.5.2 마우스 조작 성능

바뀌지 않은 전선의 경로·거리 계산 자료를 재사용하고, 포인터 강조를 화면 프레임에 맞춰 한 번만 그립니다. SVG 내용이 같으면 DOM을 교체하지 않습니다. 전선 수정·되돌리기·타이 이동 시에는 계산 자료를 다시 만듭니다.

JavaScript와 CSS를 별도 파일로 옮기는 것 자체는 프레임 개선이 아니므로 단일 HTML 실행 방식은 유지합니다. 측정 방법과 결과는 [성능 점검](docs/performance.md)에 있습니다.

## 2.5.1 표시등 배선 모양

HMI 아래쪽 표시등의 전선은 단자 왼쪽에서 들어오도록 90도로 꺾입니다. 같은 나사에 연결한 두 선은 위아래로 나란히 놓이며, 케이블 타이로 묶어도 단자 옆 직선 구간을 유지합니다. 전기적 연결과 저장 형식은 바뀌지 않습니다.

## 2.5 단자대와 배선 자유도

- 상단 **단자대 견출지** 또는 **견출지(L)** 도구로 단자대의 흰 이름표를 눌러 편집합니다. 빈칸·중복 이름도 가능하며 이름표는 전기적 기능을 지정하지 않습니다.
- S+ 등 외부 선을 다른 번호로 옮겨도, 내부 배선과 외부 결선이 함께 맞으면 실제 회로로 작동·검사합니다. 단자대 번호만으로 AC/DC를 정하지 않습니다.
- 전원 케이블은 꽂을 R선 단자와 T선 단자를 차례로 선택합니다. 전원 위치도 이름표와 별개이며 1·2번으로 고정되지 않습니다.
- 배선 목록에서 예시와 다른 선을 오답으로 표시하지 않습니다. 배선 검사는 외부 전원선과 컨베이어 선을 연결한 뒤 진행합니다.
- 추가로 발견한 고정 조건과 남은 한계는 [배선 자유도 점검](docs/wiring-flexibility.md)에 정리했습니다. 연습용 예시·배치·조작판 조건이 모두 자유화된 것은 아닙니다.

## 2.4 초보자를 위한 기구 해설

**기구 해설(I)** 도구로 설치된 기구를 누릅니다. 기본 화면은 다음 순서로 보여줍니다.

1. 기구의 실제 모양과 하는 일 한 줄
2. 현재 내 배선에서 계산한 상태
3. 릴레이는 두 갈래 길 그림, 타이머는 3단계 순서와 남은 시간
4. 직접 조작해 볼 방법이나 꼭 기억할 내용

단자 번호·모델명·전문 결선도는 **단자 번호·자세한 정보가 필요할 때**를 펼쳐서 확인합니다. 다른 기구로 바꾸면 다시 접힙니다. 창을 열어 둔 채 손(H) 도구로 버튼과 센서를 조작하면 그림과 설명도 실시간으로 바뀝니다. 해설을 보는 것만으로 기구나 배선이 바뀌지는 않습니다.

시험 중에는 해설을 숨기며 제출 뒤 다시 사용할 수 있습니다. 작업판에 선이나 접점 상태를 덧그리는 기능은 없습니다. 기존 저장 데이터 형식도 유지합니다.

## 2.2 기능

- 채점표의 미완료·감점 항목에서 **관련 위치 보기**를 누르면 부품이나 단자로 이동하고 빨간색으로 강조합니다. 자유 모드와 시험 제출 후에 사용할 수 있습니다. 동작 항목은 검사할 관련 부품·단자를 보여주며, 구체적인 원인은 감점 설명과 테스터로 확인합니다.
- **단자 검색**에서 `R3`, `PLC P20`, `TB 1번`, `부저`처럼 기호나 한글 이름으로 설치된 단자를 찾습니다. 조작판 단자는 필요하면 뒷면으로 전환합니다.
- **연결 추적**은 현재 꽂은 전선, 단자대 위아래·SMPS 공통선, 컨베이어 결선을 따라 연결된 단자와 전선을 강조합니다. 접점의 통전 상태와 전압은 테스터로 확인합니다.
- 강조는 Esc, **강조 지우기**, 작업 변경·초기화·모드 전환 시 해제됩니다. 저장 데이터 형식은 기존 버전과 같습니다.

## 자동 검증

Node.js 20 이상이 필요합니다.

```sh
npm ci
npx playwright install chromium
npm test
```

Linux에서 브라우저 시스템 라이브러리도 필요하면 `npx playwright install --with-deps chromium`을 사용합니다. 기존 Chromium을 사용할 때는 `CHROMIUM_PATH=/usr/bin/chromium npm test`로 실행합니다. npm 캐시 경로가 쓰기 금지된 환경에서는 `npm ci --cache /tmp/html-npm-cache`를 사용할 수 있습니다.

검증은 임시 로컬 HTTP 서버와 별도의 브라우저 저장 공간을 사용하며 사용자 작업은 건드리지 않습니다. 외부 폰트 없이도 실행합니다.

검증 대상:

- 정답 배선의 회로 검사 15개, 컨베이어 동작 검사 11개, 만점 30점
- 고장 10종 각각의 검출·감점 및 복구 후 통과
- 채점 위치 이동과 작업 상태 보존
- 기호·한글 검색, 실제 배선 추적, 검색 입력 중 도구 단축키 방지
- 빈 작업, 모드 전환, 시험 중 채점 위치 안내 제한
- 자유·시험 작업의 독립 저장 및 새로고침 복원
- 모바일 화면의 검색창과 위치 이동
- 릴레이의 실제 4극 전환과 초보자용 길 그림, 타이머 순시·한시·남은 시간과 전원 OFF 복귀
- 표시 접점과 회로 계산의 일치, 미장착 소켓, 기구 해설의 읽기 전용 조작
- 모든 설치 기구의 쉬운 역할·현재 상태, 기본 화면에서 전문 용어와 단자 정보 숨김
- 선택형 상세 정보, 작업판 접점 표시 제거, 시험 제한, 좁은 화면·어두운 테마의 해설 창

GitHub Actions는 push와 pull request에서 같은 검증을 실행합니다. 브라우저 조립 작업 전체를 수동으로 완주하는 테스트는 포함하지 않습니다.
