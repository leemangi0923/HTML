# 3D 기구 외형 조사와 모델링 범위

2026-11-09 조사. 기구의 설치 좌표와 평면 치수는 원본 `index.html`의 완성 예제를 그대로 사용한다. 원본 제품 그림을 윗면에 재사용하고 입체 구조를 보강한다. 아래 자료 접근 결과를 제조사 CAD 또는 실측 치수 확보로 해석하지 않는다.

| 조사 대상 | 접근한 자료 | 결과·반영 범위 |
| --- | --- | --- |
| Autonics SPB-120-24 | https://www.autonics.com/ | 환경의 HTTPS 프록시가 CONNECT 403으로 차단. 제조사 제품 사진·CAD·깊이 치수는 새로 확인하지 못함. 원본 SPB 그림을 유지하고 통풍구를 근사 모델링. |
| LS XGB XBC-DN32H / L7S | https://www.ls-electric.com/ | 같은 접속 제한. 원본 PLC/서보 그림과 평면 치수를 유지하고 케이스·측면 통풍구·커넥터를 근사 모델링. |
| KACON HR705-4PL / 소켓 | https://www.kacon.co.kr/ | 같은 접속 제한. 원본의 투명 릴레이 케이스·구리 코일·단자 배열을 입체로 보강. |
| 한영넉스 T38N | https://www.hanyoungnux.com/ | 같은 접속 제한. 원본 베이지 케이스·다이얼·파란 고정 클립을 보강. |
| 공개 XGB 학습 자료 | https://github.com/nalutbae/awesome-pcq/blob/main/README.md | 접근 가능. XGB 모델 계열과 입출력 구성을 다루는 2차 자료이며 외형 실측·CAD 근거는 아님. 외부 이미지·본문을 앱에 복제하지 않음. |

GitHub 공개 저장소 검색에서 `SPB-120-24`, `KH-RS-14M`, `HR705`, `Autonics SPB`에 대응하는 외형 자료 저장소는 찾지 못했다. T38N의 검색 결과는 대상 제품과 관련 없는 저장소여서 사용하지 않았다. 다른 제조 현장의 XBC-DN32H 자료는 해당 작업대와 다른 구성이므로 외형 근거로 사용하지 않았다.

## 현재 모델의 정확도

- 제어판·조작판·기구의 가로/세로 치수와 설치 위치: 원본 완성 예제 기준.
- 345개 나사와 덕트 핑거: 원본 단자 배열/덕트 크기를 바탕으로 생성한 시각화. 제조사의 3D CAD를 사용한 것이 아님.
- 소켓·투명 케이스·코일·다이얼·클립·통풍구·커넥터·모든 높이/깊이: 원본 제품 그림에서 추정한 교육용 외형.
- 작업실, 책상 다리, 책상 높이 750mm, 사람 눈높이 1600mm, 몸 반경 200mm: 걸어 다니는 감각을 위한 가정. 실제 사용자 작업실을 복원했다고 주장하지 않음.
- 1인칭 충돌: 작업대 전체를 덮는 직육면체와 방 경계에 대한 몸 반경 검사. 실제 전선·기구의 정밀 충돌, 손 조작이나 전기적 안전 판정은 아님.

실제 사진과 실측 높이를 받으면 이 근사값을 교체할 수 있도록 모델 세부 구조와 이동 처리를 별도 모듈로 분리했다. 외부 이미지를 추가로 다운로드하거나 재배포하지 않았다.
