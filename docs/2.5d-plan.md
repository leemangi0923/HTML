# 기본 시뮬레이터의 은은한 입체감 · 수정된 8차 계획

2026-11-11 사용자 수정: **실물 사진의 형태와 재질 재현을 먼저 하고, 그다음 얕은 옆면을 맞춥니다.** 기존 그림에 그림자만 붙이는 방식으로 그래픽 개선이 완료됐다고 보지 않습니다. 사진에 없는 구멍·통풍구·패널을 장식으로 추가하지 않습니다. 확인할 원본이 없는 기구의 구조는 추측으로 바꾸지 않습니다.

v2.28.0에서는 새로 제공된 IO링크 제품 사진 3장을 기준으로 정면과 투명 커버를 다시 그렸습니다. [사진 반영 항목과 실제 화면](io-link-graphics.md). 덕트·찬넬은 뒷면에 테이프를 붙이고 철판에 설치할 때 정면으로 뒤집히는 [작업 과정](frame-back-tape.md)을 반영합니다.

v2.29.0에서는 사용자가 제공한 비교 그림에 맞춰 **설치된 바닥면을 고정하고 윗면이 움직이도록** 투영 기준을 수정했습니다. 고정된 윗면에서 옆면을 그림자처럼 늘리던 이전 방식을 대체합니다. [수정 전후 확대 비교](anchored-projection.md).

사용자가 말한 2.5D는 **기존 시뮬레이터를 계속 사용하면서 부품에 높이가 느껴지고, 화면을 오른쪽으로 옮기면 오른쪽 옆면이 조금 더 보이는 표현**입니다. v2.23.0의 별도 WebGL 시연은 이 의도와 달라 v2.24.0에서 정리했습니다. v2.27.0에서는 제어판 기구·조작판·컨베이어까지 옆면과 재질 표현을 확장했습니다. [적용 범위와 화면](device-materials.md).

현재 SVG 화면의 그림과 조작을 기준으로 진행합니다. 설치 좌표를 기준으로 윗면·단자·전선 끝을 화면에 투영하며, 클릭은 모델 좌표로 역변환합니다. 회로와 저장의 단자 좌표는 유지합니다. 각 차수의 결과는 기본 작업 화면에 적용합니다.

## 현재 구현 방식 · v2.29.0에서 기준 수정

바닥은 원래 설치 자리에 고정하고, 화면 중심과 부품 위치·높이에 따라 윗면을 이동합니다. 그 사이를 옆면으로 연결합니다. 최대 이동량은 표시 높이의 가로 9%, 세로 6.5%로 제한합니다. 아래 부품 위에 붙는 커버와 본체는 받침의 이동과 자기 높이를 함께 반영합니다.

화면 이동 시 기존 부품과 전선 노드를 유지하고, 윗면 변환과 옆면·표시용 전선 경로를 갱신합니다. 실제 연결·경로 계산·회로·채점·저장 상태는 그대로 사용합니다. 마우스 이동만으로 시야가 흔들리지 않으며 보이는 표면의 클릭을 원래 작업 좌표로 변환합니다.

**설정 → 은은한 입체감**에서 끌 수 있습니다. 화면 설정만 따로 저장합니다. 게임은 단일 HTML과 기존 Electron 구성으로 실행되며 새 렌더링 라이브러리가 필요하지 않습니다.

실제 화면·사진에 맞춘 스토퍼·검증 결과는 [1차 기록](2.5d-stage1.md)에 정리했습니다.
