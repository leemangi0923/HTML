# 기본 시뮬레이터의 은은한 입체감 · 수정된 8차 계획

사용자가 말한 2.5D는 **기존 시뮬레이터를 계속 사용하면서 부품에 높이가 느껴지고, 화면을 오른쪽으로 옮기면 오른쪽 옆면이 조금 더 보이는 표현**입니다. v2.23.0의 별도 WebGL 시연은 이 의도와 달라 v2.24.0에서 정리했습니다. v2.27.0에서는 제어판 기구·조작판·컨베이어까지 옆면과 재질 표현을 확장했습니다. [적용 범위와 화면](device-materials.md).

현재 SVG 화면의 그림과 조작을 기준으로 진행합니다. 부품별 옆면·접촉 그림자와 얕은 시차를 단계적으로 다듬으며, 화면 전체를 회전하거나 기존 단자 좌표를 다른 입체 공간으로 옮기는 작업은 하지 않습니다. 각 차수의 결과는 기본 작업 화면에 적용합니다.

| 차수 | 범위 | 완료 기준 |
|---|---|---|
| **1차 · v2.24.0 구현** | 철판·덕트·찬넬·스토퍼의 얕은 옆면과 그림자. 실제 UA-52 스토퍼 반영 | 기존 화면에서 좌우 이동에 따라 보이는 면 변화, 단자·배선·채점 유지 |
| 2차 | 소켓·MCB·퓨즈 홀더·SMPS·PLC·서보의 높이감 | 현재 제품 그림을 유지하며 몸체의 얇은 옆면과 층 높이가 자연스러움 |
| 3차 | 릴레이·타이머 상세 재질 | 투명 커버·내부 코일·다이얼·소켓 간 깊이 차이를 절제해서 표현 |
| 4차 | 단자·나사·전선 끝의 깊이감 | 단자 번호와 클릭 위치가 맞고, 선 끝이 단자에서 떠 보이지 않음 |
| 5차 | 덕트·전선의 겹침 | 덕트 안과 밖, 커버, 전선 높이와 그림자가 자연스럽고 실제 경로·연결은 같음 |
| 6차 | 타이·헬리컬 밴드·테스터 표시 | 밴드 고정 구간 유지, 묶은 선의 층과 측정 표시가 읽기 쉬움 |
| 7차 | 조작판·HMI·버튼·컨베이어 | 제어판과 같은 정도의 입체감, 앞뒤 전환·안내·모드별 조작 유지 |
| 8차 | 전체 표현과 성능 마무리 | 배선이 많은 화면에서도 이동이 부드럽고, 기존 모드·저장·설치형 검사 통과 |

## 1차 구현 방식

기존 윗면은 제자리에 두고 그 뒤에 얇은 SVG 옆면을 그립니다. 화면 중심과 부품 위치의 차이에 따라 보이는 옆면의 방향과 폭을 천천히 바꿉니다. 높이가 있는 덕트의 옆면은 낮은 찬넬보다 조금 넓습니다. 최대 폭은 표시 높이의 9%, 세로 방향은 6.5%로 제한해 기본 작업판 느낌을 유지합니다. 이것은 절제한 그래픽 효과이며 정밀한 3D 투영이나 치수 측정 기능이 아닙니다.

화면 이동 시 기존 부품과 전선 노드를 유지하고 옆면의 경로만 갱신합니다. 마우스 이동만으로는 시야가 흔들리지 않습니다. 효과가 붙은 옆면은 클릭을 가로채지 않습니다. 단자와 원래 부품의 윗면에서 작업하며, 기존 회로·채점·저장 상태를 그대로 사용합니다.

**설정 → 은은한 입체감**에서 끌 수 있습니다. 화면 설정만 따로 저장합니다. 게임은 단일 HTML과 기존 Electron 구성으로 실행되며 새 렌더링 라이브러리가 필요하지 않습니다.

실제 화면·사진에 맞춘 스토퍼·검증 결과는 [1차 기록](2.5d-stage1.md)에 정리했습니다.
