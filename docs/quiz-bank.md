## 076 · 동작·진단

조건: 출제용 개념도입니다. 별도 표시가 없는 전원·공통선은 정상이고, 접점을 우회하는 다른 공급 경로는 없습니다. R3는 일반 비유지형 릴레이입니다. R3 코일은 OFF입니다.

- 정답: R3 a접점이 열려 공급 경로가 끊긴다
- 오답: R3 a접점이 닫혀 공급된다
- 오답: 퓨즈가 자동으로 우회된다
- 오답: PLC 입력만 바뀌고 공급은 유지

해설: R3는 일반 비유지형 릴레이예요. 이 예시에서는 a접점이 PLC 전원 경로에 직렬로 연결돼 있어요.

## 077 · 동작·진단

조건: 출제용 개념도입니다. 별도 표시가 없는 전원·공통선은 정상이고, 접점을 우회하는 다른 공급 경로는 없습니다. R3는 일반 비유지형 릴레이입니다. 운전 허가 접점은 열린 상태입니다.

- 정답: 전원은 유지되고 허가 입력이 꺼진다
- 오답: PLC 자체 전원도 반드시 꺼진다
- 오답: 입력 공통선이 자동 단선된다
- 오답: PLC 출력이 모두 켜진다

해설: PLC 전원 공급 경로와 운전 허가 입력 경로가 별개인 조건이에요.

## 078 · 동작·진단

제시된 선택 스위치를 수동으로 전환하면?

조건: 출제용 개념도입니다. 별도 표시가 없는 전원·공통선은 정상이고, 접점을 우회하는 다른 공급 경로는 없습니다. R3는 일반 비유지형 릴레이입니다. PLC 전원은 계속 공급되며 자동 위치 접점은 수동에서 열립니다.

- 정답: PLC 전원은 유지되고 자동 운전 허가 입력이 꺼진다
- 오답: PLC 전원이 반드시 꺼진다
- 오답: 모든 입력이 켜진다
- 오답: SMPS 출력 전압이 바뀐다

해설: 자동 위치 접점은 수동에서 열리며 PLC 전원은 별도 경로로 계속 공급되는 조건이에요.

## 086 · 동작·진단

3초 ON 지연을 원하지만 그림처럼 즉시 a접점을 사용했다. 예상되는 문제는?

조건: 출제용 개념도입니다. 전원 투입형 3초 ON 지연 타이머에 즉시 a접점과 한시 a접점이 모두 있으며, 다른 공급·우회 경로 없이 즉시 a접점을 출력에 사용했습니다.

- 정답: 3초를 기다리지 않고 출력 경로가 연결될 수 있다
- 오답: 항상 3초 뒤에만 연결된다
- 오답: 퓨즈가 반드시 끊어진다
- 오답: 출력이 영원히 차단된다

해설: 이 타이머는 즉시·한시 접점을 모두 가진 예시예요. 지연 출력에는 조건에 맞는 한시 접점을 사용해야 해요.

## 087 · 동작·진단

전원 투입형·비유지형 ON 지연 타이머의 설정은 3초다. 전원이 1초 공급된 뒤 완전히 초기화될 만큼 차단되는 상황이 반복된다. 한시 a접점이 닫히지 않는 이유는?

조건: 전원 투입형·비유지형 ON 지연, 설정 3초. ON 1초 뒤 매번 완전히 초기화되기에 충분한 시간 동안 OFF. 차단 시간을 임의의 짧은 순간으로 가정하지 않습니다.

- 정답: 매번 초기화돼 설정 시간 3초에 도달하지 못해서
- 오답: 전원이 없어도 시간이 계속 누적돼서
- 오답: 즉시 접점만 초기화돼서
- 오답: 설정값이 자동으로 1초가 돼서

해설: 전원 투입으로 시간 측정을 시작하고, 차단 시간은 제품이 완전히 초기화되기에 충분하다는 조건이에요.
