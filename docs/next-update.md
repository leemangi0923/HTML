# 다음 업데이트 참고 사항

## 업데이트 운영 원칙 (2026-11-18)

일반 수정은 웹 링크에만 반영합니다. Windows 설치 파일 빌드, 버전 태그, Releases 및 앱 자동 업데이트 게시는 사용자가 배포를 명시적으로 요청할 때만 진행합니다. 웹 수정으로 Windows 빌드를 자동 실행하지 않습니다.

## 웹 반영: HMI 철판을 조립한 뒤 상판에 부착

HMI·본체 → 뒷면 은색 고정 링 → 앞면 비상정지 캡 → 상판 지지대 순서로 조립합니다. 링·캡은 각각 별도 재료이며 철판 구멍과 프로파일 T홈 표현을 수정했습니다. [조작과 저장 호환](operator-assembly.md)

## 로봇 제어기 단자명과 실제 결선

- 요청일: 2026-11-16
- 제어기는 뒤집어 쓰는 방향을 기본으로 합니다.
- 사용자가 제공한 사진의 타공 커버 면과 90도 열린 작업 면은 v2.49.0에 반영했습니다.
- 녹색 단자대의 연결 위치를 선택할 수 있으며, 실제 단자명·신호·결선 규칙은 사용자가 추가로 지시할 예정입니다.
- 사진만으로 단자 번호와 신호를 추정해 기존 채점 회로에 연결하지 않습니다.
- [현재 구현 화면](viewport-and-controller-photos.md)
