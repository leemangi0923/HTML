# 2.18.0 · 고장 학습과 기기 내 랭킹

메인 → **실전 고장 실습**에서 10개 사례를 모두 자유롭게 선택합니다. 처음에는 고장 1~10으로 표시하고, 직접 수리해서 실제 배선·운전 검사를 통과한 고장만 이름을 공개합니다. 힌트를 보거나 검사에 실패한 것만으로는 공개하지 않습니다. 해결 기록은 재시작해도 유지합니다.

| 모드 | 출제 | 힌트 한도 |
|---|---|---|
| 선택 학습 | 10종 중 직접 선택, 고장 1개 | 4단계·정답까지 |
| 입문 | 10종 중 무작위 1개 | 3단계·핵심 해결 방법까지 |
| 도전 | 증상이 서로 드러나는 19개 조합 중 2개 | 2단계·가벼운 해결 방법까지 |
| 랭크 | 같은 10종을 무작위 순서로 하나씩 모두 해결 | 힌트 없음 |

힌트는 **고장 종류 → 가벼운 해결 방법 → 핵심 해결 방법 → 정답** 순서입니다. 핵심 위치 표시는 3단계부터 가능합니다. 랭크에서는 힌트 버튼·위치 표시를 제공하지 않으며, 검사 실패 시 미통과 동작만 표시합니다. 완료한 고장의 정답 해설은 모든 모드에서 볼 수 있습니다.

랭크의 다음 고장은 현재 고장을 해결한 뒤에만 열립니다. 10개를 모두 해결해야 한 기록이 남습니다. 난이도 차이 없이 동일한 10종을 비교하고, 메뉴·결과창·앱 종료 시간까지 시작부터 마지막 성공까지의 총시간에 포함합니다. 진행 상태와 출제 순서는 저장됩니다. ‘랭크 처음부터’는 10개 전체를 다시 시작합니다.

## 랭킹 규칙

메인의 **기기 내 랭킹**에서 닉네임을 저장합니다. 각 작업을 시작한 시점의 이름을 사용하므로, 중간에 이름을 바꿔도 다른 사람의 기록으로 옮겨지지 않습니다. 같은 이름의 최고 기록 하나를 표시하며, 같은 성적과 시간은 공동 순위입니다.

- **시험**: 제출 시 점수 내림차순 → 시간 오름차순. 자동 시간 초과 제출도 기록합니다. 예시 채우기 사용은 제외합니다. 기존 시험 타이머(화면 작업 시간)를 사용하며, 선 준비 시간 및 자기 점검 항목도 채점 결과에 포함합니다. 제출 뒤 자기 점검 항목을 바꿔도 저장한 성적은 바뀌지 않습니다.
- **선 따기**: 실제 20가닥 작업의 직접 점검 불량 개수 오름차순 → 시간 오름차순. ‘끝’ 뒤 점검을 마치고 ‘기록 저장’을 눌러야 기록합니다. 앱이 실제 작업을 자동 검증하는 기록은 아닙니다.
- **고장**: 무힌트 랭크의 10개 전체 완료 시간 오름차순. 학습·입문·도전 및 중도 종료는 포함하지 않습니다.

저장 공간은 같은 브라우저 또는 설치형 앱 안에서만 공유합니다. **온라인 서버가 연결된 랭킹이 아닙니다.** 브라우저와 설치형 앱도 각각 별도 기록입니다. 저장 실패는 알리고, 저장했다고 표시하지 않습니다. 최신 1,000개 랭킹 기록에서 이름별 최고 기록을 표시합니다. 기존 구버전 기록은 당시 이름·제출 상태가 없으므로 소급 등록하지 않습니다.

로컬 데이터는 사용자가 수정할 수 있으며, 온라인 경쟁을 위한 부정행위 방지 기능은 제공하지 않습니다.
