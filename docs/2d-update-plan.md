# 2D HTML 업데이트 계획 — 2026-11-10

상태: **2번은 v2.14.0에서 구현 완료, 4번은 v2.15.0에서 구현 완료**. 사용자 요청으로 1번·3번은 진행하지 않습니다. 3D 작업실은 종료하고 기존 1과제 2D 시뮬레이터를 개선합니다. 퀴즈를 다시 만들지 않습니다.

## 현재 기능과 구분

단자 검색·연결 추적·감점 위치 이동, 초보자용 기구 해설, 시연 보기, 연습 챕터 7의 고장 10종, 자유/시험 각각의 자동 저장, 배선 목록 텍스트 내보내기·불러오기는 이미 있습니다. 아래는 제안 당시 계획과 현재 진행 상태입니다.

## 1. 전체 작업 백업·복원 — 진행하지 않음

현재 배선 목록 내보내기는 작업 전체의 백업이 아닙니다. 기구 배치·견출지·타이·밴드·타이머 설정·결선 상태를 한 파일로 보관하고 다른 PC에서 이어 하도록 합니다.

- 브라우저 기본 다운로드/파일 선택을 사용해 전체 작업 JSON을 내보내고 읽습니다.
- 복원 전에 작업 이름, 저장 날짜, 모드, 진행 단계와 배선 개수를 보여줍니다.
- 자유 작업 또는 시험 기록 중 무엇을 바꿀지 명확히 표시합니다. 교체 직전 상태를 복구용으로 보관합니다.
- 손상된 파일·지원하지 않는 버전은 현재 작업을 바꾸지 않고 안내합니다.
- 시험을 진행 중인 상태에서는 외부 작업을 덮어쓸 수 없게 하고, 시간·제출 상태가 바뀌는 편법을 막습니다.
- 검증: 내보내기→다른 브라우저 공간에서 복원 후 같은 배치·타이·밴드·결선·점수, 구버전 읽기, 잘못된 파일, 다른 모드 보존.

처음에는 파일 백업·복원부터 구현하고, 이름 붙인 여러 작업을 저장하는 보관함은 필요할 때 추가합니다.

## 2. 실전 고장 실습 — v2.14.0 구현 완료

기존 10개 고장은 이름과 순서가 정해져 있습니다. 이를 바탕으로 **어디가 고장인지 알려주지 않고 증상만 보여주는 무작위 실습**으로 확장합니다. 객관식 문제 대신 작업판에서 테스터로 확인하고 실제 배선을 고칩니다.

- 입문: 검증된 고장 1개를 무작위로 선택. 도전: 충돌하지 않는 고장 2개 조합.
- 예: 램프가 안 켜짐, 센서에 반응하지 않음, 타이머 후 다음 동작이 안 됨.
- 증상은 생성한 회로를 실제 실행해 확인합니다. 서로 상쇄되거나 복구 불가능한 조합은 출제하지 않습니다.
- 힌트는 확인할 범위→측정할 두 지점→원인 순으로 선택해 엽니다.
- 통과는 예시의 전선 쌍과 비교하지 않고 고장 복구 후 필요한 동작 검사로 판정합니다.
- 자유/시험의 기존 작업과 별도 상태를 사용합니다. 시험의 타이머·제출 기록을 바꾸지 않습니다.
- 검증: 모든 생성 조합에서 실제 고장 검출, 복구 후 통과, 동일 원인 반복 편중 완화, 기존 정상 동작 유지.

메인 메뉴에 **실전 고장 실습**을 추가했습니다. 입문 10종·검증된 도전 조합 19개, 단계별 힌트, 현재 동작 기반 판정, 별도 저장·이어 하기를 지원합니다. 같은 사례 다시 하기와 새 사례 뽑기를 구분합니다.

## 3. 동작 기록창 — 진행하지 않음

지금 기구 해설은 현재 상태를 보여줍니다. 기록창은 **무엇이 먼저 바뀌어 다음 동작이 일어났는지**를 보여줍니다.

- PB1 누름, 릴레이 붙음/떨어짐, 타이머 시작/완료/초기화, 센서 감지, 모터 정지/방향 변경을 시간 순으로 기록합니다.
- 항목을 누르면 관련 기구 위치로 이동하고 짧은 설명을 보여줍니다.
- 기록은 상태가 바뀔 때만 남기고 최대 개수를 제한합니다. 일시정지·비우기·기구 필터를 제공합니다.
- 자유 모드와 고장 실습에서 사용하고 시험 중에는 해설성 기록을 숨깁니다.
- 검증: 실제 회로 상태와 기록 일치, 타이머 완료/초기화 구분, 모드 전환 시 기록 혼합 방지, 성능 저하 여부.

예: “PB1 누름 → R3 붙음 → 해당 접점 닫힘 → PLC 전원 공급”. 실제 결선에서 확인된 사건만 표시하며 예시 순서를 강제로 보여주지 않습니다.

## 4. 완성 배선에서의 반응 속도 개선 — v2.15.0 구현 완료

실측한 SVG 전체 교체와 타이 이동의 반복 계산을 개선했습니다. 저사양 표시 옵션과 JS/CSS 파일 분리는 추후 측정 결과에 따른 검토 후보로 남깁니다.

이미 적용한 포인터·카메라 갱신 묶기와 전선 경로 캐시를 유지하면서, 선이 많은 상태에서 남은 병목을 측정합니다.

- 완성 예제의 확대·휠 버튼 이동·선 선택·타이 이동·동작 중 장면을 같은 환경에서 비교합니다.
- 바뀐 기구·선만 갱신할 수 있는 구간을 찾고, 자동 저장과 전체 SVG 재생성 비용을 측정합니다.
- 저사양 표시 옵션은 글씨·단자 선택 정확도를 유지하면서 그림자·장식 효과만 줄입니다.
- JS/CSS 파일 분리는 유지보수 필요로 판단하며 그 자체를 FPS 향상으로 홍보하지 않습니다.
- 검증: 전후 입력 반응 시간과 프레임 간격, 마지막 드래그 위치 보존, 배선·채점 결과 일치. 사용 기기에서의 수치가 없으므로 특정 FPS는 약속하지 않습니다.

## 추천 순서

사용자가 **2번·4번만 진행**하기로 선택했습니다. 2번 실전 고장 실습을 먼저 구현했고, 성능 개선은 작업판 부분 갱신·동작 중 경로 재사용·타이 이동 계산 묶기로 구현했고, 측정 결과는 성능 문서에 기록했습니다. 1번·3번은 구현하지 않습니다.
