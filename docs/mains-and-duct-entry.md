# v2.26.0 · 콘센트와 덕트 진입

동작 검사 재료에 접지 콘센트를 추가했습니다. 제어판 아래 바닥에 놓고, 손 도구로 전원 플러그를 누른 뒤 콘센트 가운데를 누르세요. 꽂힌 플러그를 누르면 빠집니다. 선택은 노란 원으로 표시하며 Esc로 취소합니다. 플러그를 빼도 단자대의 R/T/E 배선은 유지됩니다.

전원은 콘센트가 있고 플러그가 꽂혀 있으며 R/T/E가 정상 배선되어야 공급됩니다. MCB를 올려도 플러그가 빠져 있으면 전압·기구·컨베이어 동작이 차단됩니다. 연결 상태는 작업에 저장되고 검사 키에도 반영됩니다. 이전 저장에 플러그 연결 정보가 없으면 자동으로 전원을 공급하지 않습니다. 연습·시연·예시 회로에도 콘센트와 플러그 단계를 반영했습니다.

코드는 묶지 않은 한 줄의 곡선으로 수정하고 색선 끝 간격과 분기 길이를 줄였습니다. 꽂은 플러그의 핀은 콘센트 안에 가려집니다. 재료함·들고 있는 모습도 같은 코드를 사용합니다.

선 정리 도구는 이빨 사이의 기존 구멍과 이빨 아래 위치를 모두 받습니다. 클릭한 위치를 진입 좌표로 저장하고 전선을 이빨 뒤에 그립니다. 닫힌 커버, 단자와 마주 보는 벽과 3cm 범위 조건은 계속 적용됩니다. 기존 정수 구멍 ID를 그대로 읽으며 새 위치는 소수 번호로 저장합니다. 덕트 입체 표현은 유지했습니다.

검사: 실제 플러그·콘센트 클릭과 전원 차단/복귀, 뽑힌 상태 저장·복원, 이빨 아래 실제 클릭 진입과 닫힌 커버 차단, 전체 회로·연습·시연·채점 회귀 검사 및 설치형 실행 검사.
