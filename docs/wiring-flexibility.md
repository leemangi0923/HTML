# 배선 자유도 점검 (2.5)

단자대의 이름표는 표시이고, 전기 연결은 실제 전선·단자·기구의 내부 접점으로 결정합니다. 같은 동작을 만드는 배선은 여러 개일 수 있습니다. 단, 기구 자체의 핀 구성·전압·극성이나 과제의 제작 조건과 배선 예시는 구분해야 합니다.

## 이번에 수정한 제한

| 위치 | 이전 동작 | 변경 |
|---|---|---|
| `TB_LABELS`, `devTerms`, `dTB` | 40개 이름표가 상수로 고정됨 | 작업별 견출지 편집·저장·취소·되돌리기. 표시·검색·내보내기에 반영. 글씨를 바꾸어도 전기 연결은 바뀌지 않음 |
| `getChecks`, `runChecks` | 실제 동작은 컨베이어 실제 결선을 사용하지만 배선 검사는 예시 `CV_REF`를 사용 | 실제 컨베이어 결선·전원선 위치·타이머 설정으로 검사. 외부 선이 미연결이면 배선 검사가 아직 통과하지 않으며 연결 안내 표시 |
| `isAC`, `isDC`, `mixesACDC` | TB 1·2번은 AC, 4번 이후는 DC로 간주. 타이머 접점도 모두 DC로 분류 | 단자대와 타이머의 무전압 접점은 번호만으로 전압을 정하지 않음. 실제 전원선 위치와 연결된 기구로 AC/DC 혼선을 검사 |
| `dropCable`, `evalOnce`, `drawPowerCable` | 외부 전원이 TB 1·2번에 고정 | 갈색 R·파란색 T·초록색 E를 바닥에서 한 가닥씩 연결. 실제 배선의 차단기 각 극과 접지 전용 망에 맞아야 하며 TB 번호 자체는 자유. 기존 R/T 위치는 유지하고 E를 복원 |
| `runChecks`의 `p3` | R3을 강제로 붙이고 떨어뜨려 PLC를 검사 | PB1을 조작했을 때 PLC가 켜지고 꺼지는지 검사. 동등하게 작동하는 다른 릴레이 배선 허용 |
| `wireRows`, `showWireList` | 예시와 다른 전선 쌍을 오답처럼 표시 | 목록은 실제 연결을 표시하고, 옳고 그름은 기능 검사로 판단. ‘정답 채우기’도 ‘예시 채우기’로 표현 변경 |

확인한 사례: S+를 19번에서 18번으로 이동, 40개 단자 전체의 순서 재배치(전원 포함), 릴레이 R3/R6 역할 교환, 타이머 T1/T3 역할·설정 교환. 모두 실제 동작 검사를 통과하고 동작 점수 18점을 유지합니다. 반대로 이름표만 바꾸거나 안쪽 배선을 그대로 두고 외부 선만 다른 단자에 꽂으면 고장이 검출됩니다.

## 아직 고정되어 있는 부분

아래는 조사 결과이며 이번 변경에서 모두 해제한 것은 아닙니다.

| 위치 | 남아 있는 가정·제한 | 영향 |
|---|---|---|
| 연습 레슨 생성부의 `WIRE_GROUPS`, `wireNext`, `mine.every`, `CV_LEADS` | 연습은 예시의 정확한 전선 쌍과 컨베이어 목적지를 따라야 함 | 다른 정상 회로라도 해당 레슨의 통과 조건과 다를 수 있음. 자유·시험의 동작 검사는 예시 쌍을 요구하지 않음 |
| `GROUPS`, `RAIL_EXPECT`, `groupsOK`, `stage2Steps`, `scoreSheet` | 찬넬별 기구 종류·묶음·배치 순서가 고정됨. 번호도 배치 순서에서 정해짐 | 동작이 같아도 배치를 다르게 하면 제작 단계·기구 배치 점수가 달라짐 |
| `OP.answer`, `OP_ZONES`, `applyLabel` | 조작판의 구멍별 기기와 견출지 글자가 지정됨 | 버튼·표시등을 다른 구멍에 배치하거나 다른 글씨를 쓰는 자유는 없음. 단자대 견출지 편집과는 별개 |
| `prevDone`, `takeJudge` | 동작 검사 받기에 앞선 조립·배선 단계 완료를 요구 | 동작이 맞더라도 배치·제작 조건이 미완료이면 검사 버튼이 진행을 막을 수 있음. 실제 동작과 채점표 계산 자체는 별도로 실행됨 |
| `evalOnce`, `PLC_OUT_COM`, `CV_LEADS`, `TPIN` | 특정 PLC의 출력/공통, PNP 센서, 기구의 핀 구성·전원·극성이 모델에 정해짐 | 실제 기구 사양에 해당하는 제약과 시뮬레이터 모델의 한계. 출력 재지정·PLC 프로그램 편집·다른 기종 선택 기능은 없음 |
| 제작/채점 로직 | 퓨즈·기구 수, 타이 12개, 덕트/커버, 외부선 TB 경유, 단자 용량 등의 조건 | 유일한 회로 정답과는 다른 제작·물리 조건. 원본 과제지와 대조 없이 일괄 삭제하지 않음 |

다음으로 자유도를 높일 후보는 **연습용 예시 검사와 일반 동작 검사 구분 강화**, **배치 순서 고정 완화**, **동작 검사의 제작 단계 선행 조건 분리**입니다. 이 문서는 이 제한들이 제거됐다고 주장하지 않습니다.
